# 全向三轮底盘 — 开工清单

构型：3 轮 120° 均匀布局（α = 0° / 120° / 240°），每轮 1 台 AIM 一体伺服，
速度模式（CSV，模式 3）驱动，CANopen 1 Mbps，单总线 3 节点。

---

## 0. 一个前提必须先确认：轮子类型

**3 轮 120° 只能用全向轮（omni wheel），不能用麦克纳姆轮。**

麦克纳姆轮要 4 个、按「左前/右前/左后/右后 + 辊子 45° 镜像」布置，力才解耦；
3 个麦轮按 120° 排，侧向力无法解耦，数学上做不出任意方向平移。
如果结构上已经定了 3 个麦轮，就得改回 4 轮或改成全向轮 —— 这个要在加工前定死。

## 1. 站号分配表（先填这张表，再上电）

| 轮位 | α（方位角） | 站号 `2615h` | RPDO3 COB-ID | TPDO3 COB-ID | 电机下发的正转方向 |
| --- | --- | --- | --- | --- | --- |
| 前（0°） | 0° | 1 | 0x401 | 0x381 | 待实测 |
| 左后（120°） | 120° | 2 | 0x402 | 0x382 | 待实测 |
| 右后（240°） | 240° | 3 | 0x403 | 0x383 | 待实测 |

改站号流程（每台单独接、断开其它电机）：

1. SDO 写 `2615h` = 目标站号
2. SDO 写 `2614h` = 1（保存），读到 2 表示保存完毕
3. **断电重启**，新站号才生效
4. 上电确认能收到 `0x700 + 新站号` 心跳

## 2. 阶段 A：单机台架（3 台逐一过，每天最多 1 台）

每台的验收清单：

- [ ] 上位机 `YZ_CANOPEN_V2.0.exe` 能扫到节点，EDS 导入成功
- [ ] `2619h` = 9（上电默认 CANopen 控制，脉冲无效）—— 不设这个 CAN 指令全无响应
- [ ] `2601h` 驱动器输出使能 = 1
- [ ] `6060h` = 3，`60FFh` = 300，`6040h` = 0x000F → 电机低速转起来
- [ ] `6041h` bit10 置 1（速度模式=达到给定速度）
- [ ] `6040h` = 0x010F 能停，且停机后仍自锁
- [ ] 连续跑 10 分钟不报 0x20 通讯掉线

**心跳坑（务必先解决）**：`1016h` 默认 `0x7F07D0` = 每 2 秒必须收到一条心跳（或任意 CAN 指令），
否则报 **0x20 通讯掉线并停机**。台架阶段两个选择：

- 主站周期性发 `0x700 + ID`（推荐，保持默认安全行为）
- 或 SDO 写 `1016h` = 0 关闭监测（仅台架图省事，装车后要恢复）

## 3. 阶段 B：三机同总线

- [ ] 3 台同时上电，心跳都能收到，站号不冲突
- [ ] 10 ms 周期发 3 条 RPDO3，抓包确认无丢帧、无 error frame
- [ ] 逐级压周期：10 ms → 5 ms → 2 ms → 1 ms，记录从哪一级开始丢帧
- [ ] 总线负载实测（1 Mbps 下 3 轮 × 6 帧/周期，2 ms 周期约 15% 负载，1 ms 约 30%，理论都够）

RPDO3 帧格式（DLC = 7，异步 255，收到即更新）：

```
CAN ID = 0x400 + 站号
byte 0-1 : 6040 控制字 (uint16, 低字节在前)
byte 2   : 6060 工作模式 (uint8, 3 = 速度模式)
byte 3-6 : 60FF 目标速度 (int32, 低字节在前, 单位 r/min)
byte 7   : 不用（DLC=7）
```

注意 60FF 是 4 字节 **有符号**，负值要按补码发，别只填 2 字节。

## 4. 阶段 C：运动学

### 待实测参数（装车前必须量出来，填进这表）

| 参数 | 符号 | 实测值 |
| --- | --- | --- |
| 全向轮半径 | r | ___ m |
| 车体中心到轮心距离 | L | ___ m |
| 减速比（电机:轮） | i | **9**（M6030G9 内置行星减速，已确认） |
| 电机最大转速 | n_max | 3000 r/min（手册标称） |
| 单圈编码器分辨率 | — | ___ counts/rev |

### 逆解（车体速度 → 3 个轮速）

```
v_i = -sin(α_i) · vx + cos(α_i) · vy + L · ω
```

α = 0° / 120° / 240° 展开：

```
v1 =            vy + L·ω
v2 = -0.866·vx - 0.5·vy + L·ω
v3 =  0.866·vx - 0.5·vy + L·ω
```

转成电机转速下发（60FF 单位 r/min）：

```
n_i = v_i / (2π·r) × 60 × i        i = 9（M6030G9 内置行星减速比）
```

> ⚠️ **`60FFh` 是电机转速，不是轮子转速。** 想要轮子转 150 rpm，必须下发 `60FF = 1500`。
> 1500 rpm 电机版本的**输出轴上限只有 166.7 rpm**；2500 rpm 版本上限 277.8 rpm。
>
> 例：轮半径 r = 0.05 m，想让轮子走 1 m/s：
> `v_轮 = 1/(2π×0.05) = 3.18 rev/s = 191 rpm` → 超上限，需降速或换 2500 rpm 版本；
> 若走 0.5 m/s 则 `95.5 rpm × 9 = 860`（电机转速，可行）。

### 正解（3 个轮速 → 车体速度，做里程计用）

```
ω  = (v1 + v2 + v3) / (3·L)
vx = (v3 - v2) / √3
vy = (v1 - (v2 + v3)/2) / 1.5
```

> 符号和 α 的零点定义必须跟实际机械装配一致。做法：先把车架起来（轮子悬空），
> 单个轮给 +100 r/min，看它往哪个方向转，逐个确认正方向后，再填表里的「正转方向」一列。

### 里程计的一个隐患

手册 5.06.1 注明：这批电机是**单圈绝对值编码器**，刚上电时 `6064h` 读的是编码器单圈位置，
不是累计圈数。所以：

- 要么主站软件自己维护多圈计数（每次上电清零 + 增量累加）
- 要么选带电池的多圈型号，用 `2619h` 模式 6/7（上电自动回多圈零点）

三轮全向对里程计精度敏感（轮子打滑 + 无冗余），建议同时上 IMU 做航向融合，
不要单靠编码器推算。

## 5. 阶段 D：整车

- [ ] 空载调速度环 `60F9h`（P：0–10000 对应 0.0–10.0；I：积分时间 2–2000 ms，越小越刚）
- [ ] 落地跑直线：给 vx 恒定，看 3 轮实际速度是否一致（不一致就校 r 和 L 的实测值）
- [ ] 原地旋转 ω：确认 3 轮同号等速，车体不漂移
- [ ] 限速与急停：`6040h` bit8 置 1 = 急停但保持自锁；车速上限留 30% 余量
- [ ] 断线保护：拔掉一根 CAN，3 台都应在 2 s 内停机报警（靠 1016h 兜底）
